# Desk

# Overview
Desk is a single-user, Jira-like project management board built with vanilla TypeScript.  
The goal of this project is to demonstrate state management, UI architecture, and data persistence without using a frontend framework.

## Core Features
- Kanban-style board with multiple columns
- Create, edit, move, and delete issues
- Persistent state using browser storage
- Keyboard and form-based interactions

## Tech Stack
- TypeScript
- Vite
- HTML
- CSS
- Browser localStorage
